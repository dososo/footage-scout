# 许可对照:门禁结果怎么跟用户说

门禁结论不是法律意见。

| 规则 | 意思 | 对用户说 |
|---|---|---|
| R1 BLOCK | 禁止演绎(ND),但要剪辑 | 「这条不允许剪辑,不能用。」 |
| R2 BLOCK | 禁止商用(NC),但项目是商用 | 「这条不允许商用。」 |
| R3 BLOCK | 禁止 AI 生成式处理,但项目要用 | 「这条不允许交给 AI 改画面。」 |
| R4 BLOCK | 禁止用于训练 | 「这条不允许做训练数据。」 |
| R5 HOLD | 许可不明,或核验过期 | 「许可没写清楚,需要你到来源页核对,我不能下载。」 |
| R6 WARN | 相同方式共享(SA) | 「用了它,成片要用兼容的许可发布。」 |
| R7 WARN | 可能有第三方权利:配乐、可识别的人、商标 | 「请核对画面里的人、品牌和配乐。」 |
| R8 WARN / BLOCK | 纪实项目里出现 AI 生成画面 | 「这条是 AI 生成的,纪实片请说明或换掉。」 |
| R9 HOLD | 来源限定用途 | 「来源只允许特定用途,需要确认。」 |
| 无规则的 HOLD | 来源的条款还没读到官方原文 | 「这个网站的条款我没核实过。」 |

| 许可 | 商用 | 剪辑 | 署名 | 备注 |
|---|---|---|---|---|
| CC0、Public Domain Mark | 是 | 是 | 不强制,建议写 | 人物和商标权另算 |
| CC BY | 是 | 是 | 必须 | 要注明是否修改 |
| CC BY-SA | 是 | 是 | 必须 | 衍生作品同许可 |
| CC BY-NC | 否 | 是 | 必须 | |
| CC BY-ND | 是 | 否 | 必须 | |
| 美国联邦政府作品 | 通常是 | 通常是 | 建议 | NASA 等有标志、人物、第三方素材限制 |
