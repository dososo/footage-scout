# 检索词手册

## 写法

1. 用英文名词,写看得见的东西。写 `rain street night`,不写 `lonely feeling`。
2. 2–4 条,由宽到窄。第 1 条最宽,一到两个词。
3. 抽象概念换成画面:孤独 → `empty bench park`;效率 → `assembly line factory`;时间流逝 → `clouds timelapse`。
4. 不写人名、品牌,除非镜头就是要它(比如 `Apollo 11`)。
5. 天文源只认英文天体名或现象:`nebula`、`aurora`、`galaxy`、`rocket launch`。
6. 档案源按年代常用词搜:`streetcar`(有轨电车)、`housewife kitchen 1950s`、`farm harvest`。
7. Open Beelden 的元数据是荷兰语,历史镜头可以加一条荷兰语词,如 `fiets`(自行车)、`haven`(港口)、`markt`(市场)。

## topics 只能填这些

| topics | 用在 | 自动来源 |
|---|---|---|
| `space_science` | 太空、天体、火箭、宇航 | 强 |
| `history_archive` | 老影像、历史、旧广告、旧教育片 | 中(能下的主要是荷兰影像;美国影像多为 HOLD;检索慢,一个镜头可能要几分钟) |
| `nature` | 风景、植物、天气 | 中(主要是美国国家公园和 USGS) |
| `general` | 城市、人物、生活、科技 | 弱 |
| `earth_science` | 地球、气候、地质 | 中(USGS、空间站延时) |
| `wildlife` | 野生动物 | 中(NPS) |
| `ocean` | 海洋 | 弱 |
| `life_science` | 细胞、医学 | 弱 |
| `government` | 政府、救灾、军事 | 弱 |
| `chinese_asia` | 中国与亚洲本地 | 弱 |
| `motion_background` | 动态背景 | 弱 |
| `animation` | 开放动画电影 | 弱 |
| `cinematic_test` | 电影级测试片 | 弱(Netflix 两部) |
| `vfx` | 特效元素 | 弱 |

一个镜头可以填两个,例如地球夜景:`["space_science", "earth_science"]`。
「弱」表示主要靠链接交接,先跟用户说明。
