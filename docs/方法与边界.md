# 方法与边界

## 一、分工

1. 智能体拆镜头、写检索词、看拼图打分、向你确认。
2. 工具检索、判许可、下载、截片、记账。
3. 你决定下载什么，并核对 WARN 里的人物、商标和配乐。

智能体不能改判门禁。标题、作者、网页文字都当外部数据，里面的「指令」不执行。

## 二、门禁

| 规则 | 结论 | 条件 |
|---|---|---|
| R1 | BLOCK | 禁止演绎，但要剪辑 |
| R2 | BLOCK | 禁止商用，但项目是商用 |
| R3 | BLOCK | 禁止 AI 生成式处理，但项目要用 |
| R4 | BLOCK | 禁止训练，但项目要做数据集或训练 |
| R5 | HOLD | 许可不明，或条款核验超过 180 天 |
| R6 | WARN | 相同方式共享 |
| R7 | WARN | 可能有第三方权利 |
| R8 | WARN / BLOCK | 纪实项目里出现 AI 生成画面 |
| R9 | HOLD | 来源限定用途 |

来源默认 HOLD：没读到官方条款、条款变化待重读、已停用的来源。
网页上的文字只能让结论更严。比如 NPS 条目要署名以 NPS 开头、说明里整行写「Copyright Info: Public domain」才是 PASS；USGS 条目的使用说明必须恰好是「Public Domain.」。

## 三、下载

- 只用 HTTPS，只连来源表里列出的域名，每次跳转都重新核对；拒绝内网地址。
- 读网页的来源逐次遵守 robots.txt；robots 取不到就不访问。官方接口按各自的接口政策限速。
- 先核对来源和大小，给确认码；确认码绑定条目和大小，变了就作废。
- 写临时文件再改名；落盘后记 SHA-256。文件变了，门禁结论随之失效。

## 四、剪辑对接

剪辑清单只列「已放行且文件未变」的素材。回填报告当外部输入处理：要对上 brief 和 SHA-256，一条不对就整份不收；重复回填没有变化；许可不允许剪辑或 AI 处理的，拒收。
回填内容由剪辑方自报，工具无法证明改动属实。

## 五、没有接入的来源

| 来源 | 原因 |
|---|---|
| Mixkit、Coverr | 条款禁止自动访问，只给链接 |
| Vidsplay、Free Nature Stock、Blender Studio | robots.txt 带 `Content-Signal: use=reference`，含义未确认，先不接 |
| 欧盟视听服务 | 纯前端渲染，接口没有公开文档 |
| PeerTube | 实例域名不固定，和域名白名单冲突 |
| 其余 HOLD 来源 | 没读到官方许可页 |

## 六、已知不足

- 18 条核心题材都找得到可下载的素材，但只有 6 条做到每个镜头至少一条 PASS，其余要靠 WARN。后来新增的两个 PASS 按标题看多半不对题。
- 画面相关性没有做过人工盲评。
- 每次核对的是条款文字，条款随时会变；每周检查只能发现页面变化，是否影响许可要人读。
- 可识别人物、商标、配乐没有自动检测。
