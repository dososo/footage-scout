# 第三方说明

## 运行依赖

| 依赖 | 许可 | 说明 |
|---|---|---|
| httpx | BSD-3-Clause | 必需 |
| PyYAML、jsonschema | MIT | 必需 |
| mcp | MIT | 可选，MCP 服务 |
| open_clip_torch | MIT | 可选，本地画面排序 |
| PyTorch | BSD-3-Clause | 可选 |
| Pillow | MIT-CMU | 可选 |
| ffmpeg | LGPL / GPL，按构建而定 | 可选，作为外部程序调用 |

仓库不打包、不分发任何依赖。CLIP 权重（laion/CLIP-ViT-B-32-laion2B-s34B-b79K，MIT）或 SigLIP2 权重（timm/ViT-B-16-SigLIP2，Apache-2.0）由 `fsc model --download` 在你确认后从 Hugging Face 下载，锁定版本与 SHA-256。

## 来源与条款

各来源的许可、核验状态与条款页见 [`data/sources.yaml`](../data/sources.yaml)。本项目与表中任何机构没有从属或合作关系，机构名称只用于说明来源。标为 `blocked` 的站点表示本项目没有读到其官方许可页，不代表对该站点的评价。

## 示例画面

封面与 `docs/media/示例-下载素材.webp` 的画面：「Bison herd」，NPS/Neal Herbert，[来源页](https://www.nps.gov/media/video/view.htm?id=58216178-F013-4CD1-B876-12195E6079A5)写明 Public domain。使用画面不代表美国国家公园管理局认可本项目。

## 测试片段

`tests/fixtures/` 是各来源公开响应裁剪后的最小片段（合计约 160 KB），只用于测试解析器，不含视频、图片或整页文章，权利归各来源。权利人如有异议，请在 Issues 提出，会移除。

## 字体

技能图标取自思源宋体 Noto Serif SC（SIL OFL 1.1）的「寻镜」二字，已转成矢量路径，文件中不含字体。封面与截图用 macOS 系统宋体渲染成栅格图片，不含可提取的字体。
